# CryptoWorld - first website version

A responsive, static homepage for the CryptoWorld all-in-one crypto information and problem-solving platform.

## Files
- `index.html` - homepage structure
- `style.css` - responsive visual design
- `script.js` - mobile navigation and basic URL-pattern awareness demo

## Run locally
Open `index.html` in a browser.

## Deploy on Vercel
1. Create a new GitHub repository named `cryptoworld`.
2. Upload these three files to the repository root.
3. Open Vercel and choose **Add New → Project**.
4. Import the `cryptoworld` repository.
5. Keep the framework preset as **Other**. No build command or output directory is needed.
6. Deploy.

## Important limitations
The URL checker is only a front-end educational demo. It does not contact a threat-intelligence service, inspect a website, or prove that a website is safe or fraudulent. Do not use it as a security verdict. The other platform modules are currently informational placeholders and will be built in later steps.

CryptoWorld does not request or store seed phrases, private keys, or funds. Content is educational and is not financial, legal, or investment advice.
